**تحديث أكتوبر 2026:** بعد تجهيز آلية متابعة GitHub، يوجد الآن إصدار تنفيذي أحدث في `desktop/dist-next/win-unpacked/Paperclip Arabic.exe`. اختصار سطح المكتب يشير إلى هذا المسار المحدّث، والتحقق من ملفات النسخة القابلة للتشغيل نجح. النسخة الأقدم في `dist-windows` محفوظة كنسخة احتياطية للتراجع، وليست مسار التشغيل الموصى به.

تطبيق سطح مكتب مستقل في نافذة Windows يعمل بخادم Paperclip المحلي، وقاعدة بيانات PostgreSQL مضمّنة. يستعمل نسخة منفصلة عن أي تثبيت سابق ولا يحذف بيانات المستخدم.

## تشغيل نسخة التثبيت

بعد اكتمال إعادة بناء المثبّت والتحقق منه ستجد ملف `desktop/dist-windows/Paperclip-Arabic-Setup-0.1.0.exe`. افتحه لتثبيت التطبيق. أما النسخة المحدثة التي اجتازت التحقق حاليًا فهي نسخة `win-unpacked` القابلة للتشغيل مباشرة. عند التشغيل الأول، يبدأ إعداد قاعدة البيانات داخل مجلد بيانات التطبيق، وقد يستغرق بعض الوقت.

يمكنك تبديل اللغة بين **العربية** و**English** من قائمة الحساب أسفل الشريط الجانبي، وكذلك مباشرة من شاشة تسجيل الدخول ومعالج إنشاء الشركة. اختيار اللغة محفوظ في الجهاز، وتتحول الواجهة العربية إلى اتجاه **من اليمين إلى اليسار (RTL)**. عُرّبت الأجزاء الأساسية من شريط التنقل ولوحة التحكم والمشاريع والشركات وقائمة الوكلاء وتسجيل الدخول والخطوات الأولى لإنشاء الشركة والوكيل. **تنبيه:** ما زالت بعض صفحات Paperclip التفصيلية وحوارات الربط والضبط تحتوي على نصوص إنجليزية؛ النسخة عربية افتراضيًا لكنها ليست تعريبًا شاملًا بنسبة 100٪ حتى الآن.

### نتيجة الاختبارات

- اجتاز الخادم المحلي المضمّن اختبار تشغيل مستقل: استجابة `/api/health` بنجاح وتقديم واجهة عربية عبر `127.0.0.1:31288`، دون استخدام بيانات Paperclip الشخصية الموجودة على الجهاز.
- شغّلنا ملف `win-unpacked/Paperclip Arabic.exe` فعليًا على Windows، وفتح التطبيق خادمه المضمّن على `127.0.0.1:31287` بنجاح واستجاب `/api/health`، كما قدّم HTML باللغة العربية (`lang="ar"`). يشير هذا إلى عمل التطبيق محليًا؛ ولا يعد فحصًا شاملًا لجميع صفحات الواجهة.
- اجتاز فحص الأنواع TypeScript، ونجحت **48 حالة اختبار** من ثلاث مجموعات تغطي واجهة اللغة وتسجيل الدخول وقائمة الوكلاء.
- يتحقق `desktop/validate-windows.mjs --portable` من سلامة نسخة `win-unpacked` والمكونات المضمنة وتطابق ملفات واجهة المستخدم في الحزمة مع الملفات التي بُنيت من المصدر. ويفشل أمر التحقق الكامل `node desktop/validate-windows.mjs` إذا كان المثبّت أقدم من الملفات المحدثة، حتى لا يوزع بطريق الخطأ.
- **حد الاختبار:** نجاح تشغيل الخادم لا يثبت وحده أن المثبّت ينجح على تثبيت Windows نظيف تمامًا؛ ولم يُختبر بعد تنقل جميع الصفحات العربية بصورة يدوية أو التشغيل التجاري للوكلاء.

## إعادة بناء المثبّت من المصدر

المتطلبات: Windows x64، Node.js v24، pnpm 9.15.4، npm والاتصال بالإنترنت أول مرة.

```powershell
pnpm install --frozen-lockfile
pnpm --filter @paperclipai/ui build
npm install --prefix desktop/runtime --omit=dev paperclipai@2026.1012.0
node desktop/stage-runtime.mjs
node desktop/create-icon.mjs
npm install --prefix desktop/launcher
$env:ELECTRON_BUILDER_COMPRESSION_LEVEL = "1"  # بناء أسرع وحجم مثبّت أكبر قليلًا
npm run --prefix desktop/launcher dist:win
node desktop/validate-windows.mjs
```

> إذا منع Windows الروابط الرمزية خلال `pnpm install`، يستخدم هذا الفرع Junctions محلية بدلًا منها. تعتمد النماذج والوكلاء على أدوات واشتراكات مستخدم متصلة؛ لا تتوفر حسابات AI مجانية أو مفاتيح API ضمن المثبّت.

## الاحتياطات والحدود

- الخادم محلي ويستمع على `127.0.0.1:31287`؛ لا يفتح منفذًا عامًا على الإنترنت.
- تحفظ بيانات هذه النسخة داخل مسار UserData الخاص بتطبيق Paperclip Arabic، في `paperclip-data`، مستقلة عن `%USERPROFILE%\.paperclip`.
- أول تشغيل يستخدم إعدادًا محليًا آليًا بـ `paperclipai onboard --yes`; باقي التشغيل يستخدم `paperclipai run`.
- قد تحتاج الموافقة على إعدادات الأمان الأولية في Windows SmartScreen لأن المثبّت **غير موقّع رقميًا**.
- النسخة المعبأة كبيرة لأنها تضم Node.js وخادم Paperclip وPostgreSQL. وتحتاج الوكلاء إلى أدوات/اشتراكات خارجية بحسب نوع عملها.
- لا تعتمد على النسخة لإدارة الأموال أو الوصول لأسرار الشركة قبل اختبار بيئة التشغيل الفعلية ووضع صلاحيات وموافقات مناسبة.
